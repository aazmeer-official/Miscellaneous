# 📘 OOPS Concepts in JavaScript (Practice Repository)

## 📌 About This Repository
This repository is created to learn and practice basic **Object-Oriented Programming (OOPS)** concepts in **JavaScript** through lecture-based examples.

The focus is on understanding how objects are created and how classes, constructors, and inheritance work in JavaScript.

---

## 🧠 Concepts Covered

The following concepts were discussed and practiced:

- Factory Function (object creation using functions)
- Constructor Function
- Prototype Methods
- ES6 Classes
- Class Methods
- Inheritance using `extends`
- Parent class constructor using `super()`
- Creating multiple objects from a class
- Code reuse through inheritance

---

## 🎯 Learning Objectives
- Understand how objects are created in JavaScript  
- Learn the difference between factory functions and constructor functions  
- Practice using prototypes for shared methods  
- Implement classes using ES6 syntax  
- Apply inheritance between classes  
- Use `super()` to call parent class constructors
